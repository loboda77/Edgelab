# EdgeLab

Aplikacija za telefon: tekme, kvote, napovedi in stave dneva. Podatki se osvežijo vsako jutro.

Odpri https://loboda77.github.io/Edgelab/ v Safariju in izberi **Deli → Dodaj na začetni zaslon**.

Osebni podatki (stave, pologi, dvigi) so v `data/vault.json` samo šifrirani in se odklenejo z geslom v aplikaciji.
